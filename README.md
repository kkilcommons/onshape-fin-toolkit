# onshape-fin-toolkit
Parametric Onshape tools for designing surfboard fins, adding fin bases, generating molds, and preparing parts for 3D printing.

## Local Onshape setup

Copy [onshape.example.md](onshape.example.md) to `onshape.local.md` and fill in your Feature Studio and Part Studio workspace links. Git ignores the local file so personal document mappings stay out of commits. This is a reference for manual or agent-assisted uploads, not automatic synchronization. Before uploading a local `.fs` file, read the target Feature Studio and check for edits made in Onshape.
